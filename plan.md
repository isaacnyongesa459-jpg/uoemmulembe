# Mulembe Union multi-page redesign plan

## Implementation

Keep the current repository, official emblem and dependency-free HTML/CSS/vanilla-JavaScript stack. Maintain authored page fragments and route metadata in `src/`; the Python standard-library generator wraps each fragment in a shared semantic shell and emits direct-access root routes. GitHub Pages serves the repository's `main` branch root at the existing `/uoemmulembe/` URL, so commit root-level generated output and keep all site URLs repository-subpath-relative. Preserve the supplied budget PDF byte-for-byte, existing proposed budget data and actuals-unknown disclosure; preserve all source images, role-assigned portraits, separate delegate recognition and PWA.

The gallery must not rely on runtime directory enumeration. Inventory all repository image extensions and folders, identify exact duplicates and branding/app icons, then visually classify each candidate photo. Commit a JSON gallery manifest with a local original path, accurate accessible alt/caption text and a defensible category; exclude logos and app icons, avoid unnecessary duplicates, placeholders and invented events or identities. Render manifest-driven responsive cards: about 2 columns on phones, 3 on tablets, and 4+ on desktop; thumbnails remain compact and never stretch, preserve whole-image proportions when feasible, and use portrait-aware subject positioning when cover framing is needed. Lazy-load gallery images. An accessible dialog/lightbox will support close, previous/next, Escape/arrow-key navigation, click/tap targets, focus movement/restoration and touch-friendly full-screen viewing. Keep original files unchanged and link/view the supplied original image resolution.

Keep the exact leadership mappings: `1795606862985.jpg` Chairperson, `1795606968206.jpg` Treasurer, `1795609879513.jpg` Secretary, and `1795606945117.jpg` University of Embu Male Delegate. The delegate remains a distinct “Our Pride – University of Embu Leadership” recognition, explicitly not a MULEMBE Union executive official. Do not add personal names.

Revise About as a source-bounded institutional history/identity page: roots/foundation in 2016, purpose of connection and unity, respectful mention of only the supplied challenge categories, the exact named 18-subtribe section and list, a unity statement and the exact requested vision, mission and core values. Do not invent historic actors, events, dates, achievements or financial facts. Present challenges constructively and cultural identity inclusively.

Add a dedicated “Support MULEMBE Union” route. The static frontend will present five suggested Kenyan-shilling amounts, a custom whole-shilling amount, Kenyan phone format, a Donate control, instructions and pending/success/failed status vocabulary, but it must remain visibly inactive and not perform a request while the backend is absent. Define a browser-safe configurable same-origin API endpoint and a documented versioned STK Push request/response contract for future use; never include credentials, request or store an M-Pesa PIN, claim a payment worked, or synthesize success. Daraja credentials, signing, STK Push calls, callback verification/idempotency and payment status truth belong exclusively in a secure hosted backend. Keep a safe extension point rather than implementing an untestable payment service in static Pages.

Update `src/pages.json`, route generation, shared navigation/search and `service-worker.js` for the new direct donation route and gallery manifest. Keep the mobile bar compact (existing Home, Union, Events, Members, More) and expose Gallery, Leadership, Budget, Donations, Contact and remaining pages via the More drawer/sidebar. Keep PWA offline support relative to the GitHub Pages subpath, updating cache versioning and precaching the manifest plus relevant gallery source images and route resources without removing existing cache behavior.

## Design

**Movement:** heritage-inspired editorial design expressed through a restrained mobile-app shell. **Core principles:** identity without clutter; source-aware public information; persistent, predictable navigation; accessible touch and keyboard interaction. **Color philosophy:** the existing union gold (`#ffd700`) is the signature color for identity and action, balanced by ink, warm paper and muted olive neutrals. **Layout paradigm:** desktop section rail plus a flexible reading workspace; on phones, a compact app header, single-column cards and fixed bottom navigation with safe-area padding. **Signature elements:** the preserved union crest; small gold section markers; editorial cards with quiet borders and purposeful status pills. **Interaction:** actions are links or native buttons with explicit status; menus/search/lightbox are keyboard dismissible; the donation interface clearly states it is inactive and accepts no PIN. **Animation:** brief low-distance page entrance, subtle card hover and drawer/dialog motion only, disabled under reduced-motion preferences. **Typography:** Manrope for headings and DM Sans for interface/body, with system sans-serif fallbacks. **Brand essence:** a clear, trustworthy digital home for University of Embu Mulembe students; *grounded, welcoming, accountable*. **Voice:** direct, warm, factual. Example lines: “Rooted in culture. Rising together.” “Different histories. One shared home.” **Logo:** keep using the supplied official emblem without editing it. **Brand color:** union gold `#ffd700`.

## Project structure

- `src/template.html`: shared static page shell, metadata, global navigation, search, mobile More drawer, and common app script/style references.
- `src/pages.json`: route metadata, page group/navigation labels, and public search keywords.
- `src/pages/*.html`: authored, directly server-rendered route content including factual About, manifest-driven Gallery mount and inactive Donations UI.
- `data/gallery-manifest.json`: curated source-relative photo records for static generation/runtime rendering, with defensible categories, role identity labels and captions.
- `data/donation-contract.json` and `docs/daraja-integration.md`: browser-safe endpoint configuration/request schema and explicit backend-only Daraja/STK Push/callback requirements; no keys or PINs.
- `scripts/build_site.py`: generate static root HTML routes with Python standard library and incorporate/validate route metadata.
- `assets/icons.svg`: same-origin icons for navigation and shared UI.
- Root photo originals and `assets/`: uploaded images and branded app assets, preserved unchanged.
- `index.html` and other root `.html` files: generated, GitHub Pages-direct routes.
- `styles.css`, `app.js`: shared responsive styles, accessible gallery rendering/lightbox and inactive donation messaging while retaining navigation, search, budget, installation and service-worker behavior.
- `manifest.json`, `service-worker.js`, `assets/app-icon-*.png`: relative-path installable PWA metadata, logo-derived icons, and offline shell/image coverage.
- `scripts/check_site.py`: validate generated routes/navigation, full gallery manifest coverage, image files/roles/captions, donation safety, exact About facts/list, budget source integrity and PWA assets.
- `.github/workflows/pages.yml`: build and validate the root output before branch-root GitHub Pages publication.
- `README.md`, `docs/deployment.md`, `TODO.md`: user/deployment guidance, accurate integration limitations, and deliverable outcomes.
